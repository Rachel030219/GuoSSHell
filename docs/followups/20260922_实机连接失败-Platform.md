# 实机连接失败：TransportError { failure: Platform }

- 状态：**已解决**（2026-09-22）
- 记录日期：2026-09-22

## 根因

早期诊断探针把 known_hosts 的**文件路径**当目录传给了落盘管线，
`create_dir_all` 把它当父目录处理，在实机沙箱里留下了
「known_hosts 路径上是一个目录」的现场。上游 `is_known` 对
「路径存在但不是文件」一律报 `Verification`，折叠后只剩
`TransportError { failure: Platform }`——实机每次连接都在
KEX 后、认证前断开，且诊断探针（用兄弟/父目录路径）测不出问题。

模拟器沙箱没有这个残留，因此一直正常。

## 修复

`known_hosts_path()` 在返回路径前检查：路径是目录则移除（该路径上
只可能是当年探针 bug 留下的目录），是文件则不动。实机复测连接成功。
