## 现象

- **iPad 模拟器**：连接局域网内 Termux 环境的 OpenSSH 10.4 服务器（非标准端口）一切正常——TOFU、密码认证、渲染、键位输入全部可用。

## 已排除

- 本地网络权限：TCP 与 KEX 已抵达服务器，权限没问题。
- known_hosts 存储管线：修复探针文件路径 bug 后，实机上「is_known → 交互确认 → 落盘」的完整轮已验证可用（假主机 + 真实主机两轮均 OK）。

## 疑点
