# 终端缺 Nerd Font 字形（p10k 提示符显示空方框）

- 状态：待办（非阻塞）
- 记录日期：2026-09-23

## 现状

远端用 powerlevel10k 时，提示符里的 powerline / nerd 字形在终端上渲染成
空方框（豆腐块）——当前字体只有 Menlo / monospace / Courier New 回退，
iOS 不预装带这些字形的字体。纯显示问题，不影响功能。

## 下一步

内置一款 Nerd Font（p10k 官方推荐 MesloLGS NF，约 1–2 MB，四个字重），
或把它作为 Menlo 的回退只补缺字。属于资产/体积决策，M3 设置体系时
一并考虑（到时候还要让用户选字体）。
